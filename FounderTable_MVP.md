# The Founder Table — MVP (Landing + Telegram bot)

## Goal
MVP for closed founder events (8–12 people): automate applications, moderation, Hot Seat briefs and messaging.

## My role
End-to-end delivery (architecture, implementation, deployment support).  
Repo is private (client project); demo/video and docs available upon request.

## What it solves
Organizers typically run everything manually (forms, spreadsheets, DMs). MVP automates:
- Application intake and filtering
- Moderator workflow (approve/decline/Hot Seat / potential)
- Notifications and post-event follow-up messaging

## Key features
- Multi-step application form (FSM)
- Moderator controls via inline buttons (group chat)
- Hot Seat brief form with structured answers
- Lightweight “CRM” using Google Sheets

## Stack
Python, aiogram 3, Google Sheets API, Docker/Linux, HTML landing.

# FounderThemeBot — non-anonymous voting for Telegram channels (MVP)

## Goal
Enable non-anonymous voting in channels (workaround for Telegram built-in poll limitations).

## My role
MVP development + delivery, focus on UX flow, persistence, export.  
Repo is private (client project); demo/docs available upon request.

## Key features
- Admin flow via bot DM (create vote, options, publish to channel)
- Voting under a channel post via buttons
- Persistent vote log (who voted for what) + results summary
- Export (CSV) for reporting/auditing needs

## Stack
Python, Telegram Bot API, SQLite, Docker/Linux.
